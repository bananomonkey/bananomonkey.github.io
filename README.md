# РОБОТОТЕХНИКА — интернет-магазин

Статическая сборка интернет-магазина робототехники и Arduino (Next.js, `output: export`).

**Онлайн:** https://bananomonkey.github.io/

- `index.html`, `_next/`, `images/`, `banners/`, `models/` — статический сайт
- на главной — живая сцена: робот-уборщик возит жестянку в ящик
- корзина, заказы и отзывы хранятся в localStorage браузера
- `.nojekyll` обязателен: без него GitHub Pages игнорирует папку `_next`

Перепубликация: `bun run build` (без базового пути) и заменить содержимое корня репозитория папкой `out/`.
