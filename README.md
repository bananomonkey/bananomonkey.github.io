# РОБОТОТЕХНИКА — офлайн-восстановление главной страницы интернет-магазина

Рабочая локальная копия главной страницы сайта **robototechnika.ru** (интернет-магазин «РОБОТОТЕХНИКА» — всё для роботов и Arduino), восстановленная из сохранённой архивной папки `_files`.

## Как открыть

Откройте файл **index.html** двойным щелчком в любом современном браузере (Chrome, Firefox, Edge, Safari). Интернет не требуется — все стили, скрипты, шрифты и изображения лежат локально.

## Что внутри

| Путь | Содержимое |
|---|---|
| `index.html` | Восстановленная главная страница (шапка, меню, слайдер, каталог, товары, статьи, бренды, подвал) |
| `custom.css` | Минимальные «скрепляющие» стили, добавленные при восстановлении |
| `_files/` | Оригинальные сохранённые ресурсы страницы (CSS, JS, картинки) — без изменений |
| `_files/images/`, `images/` | Заново сгенерированные спрайты оформления (кнопки, иконки, стрелки), которые не сохранились браузером |
| `_files/fonts/` | Шрифты Roboto, скачанные локально для полной офлайн-работы |

## Технологии оригинала (подтверждены сохранёнными файлами)

- CMS: **1С-Битрикс: Управление сайтом** (`core.min.js`, `Bitrix.png`)
- Шаблон: **Аспро: Магазин** (классы `.wrapper`, `.top_block`, `.table_item`, `.footer_wr` и т. д.)
- Цветовая схема: сине-голубая (#3280ad, #227eb9, меню #B8C9D4→#DAE4EA) — из `template_styles.css` и `style(3).css`
- Слайдер: **FlexSlider** (баннеры 1920×300)

## Важные оговорки

- **Оригинальный HTML главной страницы утерян** (в архиве была только папка `_files`, а сайт robototechnika.ru закрыт — домен продаётся на reg.ru, в веб-архиве копий нет). Разметка восстановлена по классам CSS шаблона «Аспро» и настройкам `template_styles.css`.
- **Цены на товары — ориентировочные** (типичные для подобных товаров на момент работы магазина), а не реальные из базы сайта.
- Краткие описания товаров и анонсы статей составлены заново по названиям сохранённых изображений.
- Телефон и точные контакты неизвестны — в шапке/подвале оставлена ссылка «Заказать звонок» вместо номера.
- Структура меню и разделов каталога восстановлена по баннерам («Всё для роботов», «Всё для Arduino») и составу товаров.
- Кнопки «В корзину», «Отложенные», поиск и т. п. — визуальные элементы макета (данные оригинала не сохранились), слайдер и выпадающее меню полностью рабочие.
