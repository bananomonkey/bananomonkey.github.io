# РОБОТОТЕХНИКА — пример MVP для заказчика

Этот репозиторий — **пример MVP для заказчика**: демонстрационная версия интернет-магазина робототехники и Arduino, собранная, чтобы показать внешний вид, структуру и основные сценарии до начала основной разработки.

**Посмотреть:** https://bananomonkey.github.io/

## Что внутри

Статическая сборка (Next.js, `output: export`) — только клиентская часть, без сервера и базы данных.

- главная страница: шапка, баннеры, каталог товаров, статьи, бренды, подвал
- живая 3D-сцена: робот-уборщик возит жестянку в ящик
- корзина, заказы и отзывы хранятся в localStorage браузера

## Ограничения MVP

- нет серверной части: регистрация, оплата и реальная обработка заказов не работают
- данные о товарах, ценах и статьях — демонстрационные
- изменения в корзине и отзывах видны только в браузере того, кто их внёс

## Структура

- `index.html`, `404.html` — страницы
- `_next/` — скрипты, стили и шрифты сборки
- `images/`, `banners/`, `products/`, `brands/`, `articles/`, `payments/`, `promo/` — изображения
- `models/` — 3D-модель робота

## Публикация

Сайт размещён на GitHub Pages из корня ветки `main`.

- `.nojekyll` обязателен: без него GitHub Pages игнорирует папку `_next`
- сборка рассчитана на корень сайта, без базового пути
- чтобы обновить сайт, замените содержимое корня репозитория папкой `out/` новой сборки
