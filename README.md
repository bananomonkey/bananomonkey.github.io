# РОБОТОТЕХНИКА — пример MVP 

Этот репозиторий демонстрационная версия интернет-магазина робототехники и Arduino

**Посмотреть:** https://bananomonkey.github.io/

## Что внутри

Статическая сборка только клиентская часть, без сервера и базы данных.

главная страница: шапка, баннеры, каталог товаров, статьи, бренды, подвал
живая 3D-сцена: робот-уборщик возит жестянку в ящик
корзина, заказы и отзывы хранятся в localStorage браузера
