# bananomonkey.github.io

Персональная страница (`index.html`) и статический сайт **«РОБОТОТЕХНИКА»** —
интернет-магазин товаров для роботов и Arduino.

- Сайт РОБОТОТЕХНИКА: https://bananomonkey.github.io/robototehnika/
- Файлы сайта: папка `robototehnika/` (Next.js static export, basePath `/robototehnika`)
- `.nojekyll` в корне обязателен: без него GitHub Pages (Jekyll) игнорирует
  папки с подчёркиванием (`_next/`), и стили/скрипты не загрузятся
- Сборка состоит из текстовых файлов: изображения — в base64 (`.b64`),
  крупные скрипты — частями (`.pN.js`); их собирает на лету `sw.js`
  (Service Worker), который регистрируется страницей сайта.
- Персональная страница `index.html` сайт РОБОТОТЕХНИКА не затрагивает.

## Как обновить сайт

Заменить файлы в папке `robototehnika/` файлами новой сборки и закоммитить —
GitHub Pages пересоберёт сайт за 1–2 минуты.
